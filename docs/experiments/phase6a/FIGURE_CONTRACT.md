# Figure contract — chart-from-data

用途：GitHub README 与项目技术介绍；受控算法实验，不是官方业务测试或用户研究。

核心结论：在这 32 个预先固定的场景中，McTiming 首选更匹配偏好，但平均应付更高；覆盖率相同。只表述测得的行为，不声称统计显著或普遍提升。

证据优先级：results.json／metrics.csv／summary.csv 为推荐指标；timings.csv 为逐次实测耗时；test-summary.json／test-groups.csv 为实际自动化测试输出。历史真实价格快照不纳入算法价格图。

| 图 | 数据与独立问题 | 样本／分母 |
|---|---|---|
| 01-preference | 三算法 Top-1、默认列表平均匹配、Top-3 喜欢项并集覆盖 | 30 个有喜欢项场景，包含 7 个无推荐场景记零；2 个无喜欢项单列 |
| 02-amount | 偏好更高的代价是否为更高金额 | 三算法都有推荐的相同 25 个场景，整数分转元 |
| 03-budget-coverage | 固定请求改变预算后是否有预算内推荐 | 6 个预算点，各1个固定请求；不是不同用户总体覆盖率 |
| 04-safety-tests | 指定故障／交易边界测试实际通过多少 | 从测试结果抽取7个相关文件，共81项；另在报告给出全部测试 |
| 05-latency | 同环境离线实现的选择计算开销 | 每法960次＝32场景×30次；5轮预热，轮换顺序 |

图形选择：前3图为分组／单组柱图，第4图为带计数标签横条图，第5图为中位数柱＋P95点。独立导出，避免无关面板争夺空间；所有柱轴从零开始。无统计显著性检验或置信区间；P95是测量分位数，不是误差棒。

视觉编码：A蓝、B灰、McTiming棕，稳定跨图；同时使用文字和不同 hatch，不能只靠颜色。Arial／DejaVu Sans；图宽8英寸，字体不小于8pt。来源、n、分母和模式写入每图脚注。SVG保留 text，PNG 300dpi。

审阅风险：人工场景有选择偏差；券样例很少；默认候选数不同；相同商品的有券／无券配置可以占据不同推荐位；计时包含各实现的验证／投影开销，并非纯 sort 或线上 MCP 延迟。图表不推断市场节省金额、真实满意度或吞吐能力。

交付：scripts/plot-experiments.py、CSV／JSON源数据、5组SVG＋PNG、自动QA结果及人工检查结论。用户已明确指定上述比较和输出用途，本合约落实该范围。
